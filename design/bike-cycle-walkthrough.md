# Recreate the bike-trip cycle view

[Watch the captioned walkthrough](bike-cycle-walkthrough.mp4).

The video uses actual browser captures of the updated local app, with animated click highlights and captions. It ends at the same data and settings as the reference screenshot, using the compact schematic controls.

1. Dataset: Bike trips.
2. Measure: Mean trip duration.
3. Date range: 8–31 January 2024.
4. Layout: Cycle.
5. Arrangement: Multiples.
6. Resolution: Hour.
7. Cycle summary: Mean.
8. Values: Index 100.
9. Scale: Independent.
10. Marks: Steps.
11. Missing data: Dotted connection.
12. Appearance: Opacity 100%, Size 1.8×.

Keep the first four default origin stations selected and smoothing Off.

The SVG assets in `public/schematics/` adapt the course's visual grammar. Absolute/Index and Shared/Independent preserve cropped geometry from figures 18 and 20 in “Match View to Question”; other control thumbnails are compact versions using the same visual primitives.
